This repository contains sample assurance testing workpapers demonstrating my approach to evaluating the design and operating effectiveness of IT controls.

## Included
- Test of Design (TOD) Template
- Completed Test of Design Example
- Test of Operating Effectiveness (TOE) Template
- Completed Test of Operating Effectiveness Example
  
 ## Purpose
These templates demonstrate a structured methodology for:

- Evaluating control design
- Performing control walkthroughs
- Selecting samples
- Testing operating effectiveness
- Documenting audit observations
- Forming audit conclusions
